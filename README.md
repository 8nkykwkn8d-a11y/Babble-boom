# BUBBLE BOOM — приложение для учёта бизнеса

Русскоязычное приложение, подготовленное для установки на главный экран iPhone через Safari.

## Разделы
- Обзор склада, выручки и прибыли
- Товары и остатки
- Закупки в KRW, CNY и USD
- Доставка: сумма, коробки, вес, трек-номер и статус; доставка добавляется к себестоимости закупки
- Продажи и списание остатков
- Прочие расходы
- Калькулятор себестоимости
- Курсы валют и резервное копирование JSON/CSV

## Установка на iPhone
После публикации GitHub Pages открой ссылку приложения в Safari, нажми «Поделиться» → «На экран Домой» → «Добавить».

## Важно
Сейчас данные сохраняются локально в браузере на устройстве. Для совместной работы на iPhone и MacBook нужна отдельная облачная база и авторизация. До её подключения регулярно экспортируй резервную копию в разделе «Настройки».
