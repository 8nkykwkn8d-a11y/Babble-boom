# BUBBLE BOOM — учёт бизнеса

Русскоязычное приложение для установки на главный экран iPhone через Safari.

## Возможности
- Товары, артикулы, единицы измерения и складские остатки
- Закупки в KRW, CNY и USD с фиксацией курса в каждой партии
- Доставка с привязкой к конкретной закупке; изменение и удаление доставки пересчитывает себестоимость партии
- Продажи с фиксацией себестоимости на дату продажи
- Учёт комиссии площадки, упаковки, доставки покупателю и дополнительных затрат
- Прочие расходы с категориями
- Калькулятор себестоимости материалов
- Изменение и удаление большинства операций
- Полная резервная копия JSON и выгрузка всех разделов в CSV
- Локальная работа без постоянного подключения к интернету после первой загрузки

## Установка
После успешной публикации открой адрес GitHub Pages в Safari на iPhone → «Поделиться» → «На экран Домой» → «Добавить».

## Важные ограничения
- На текущем этапе данные хранятся локально в браузере конкретного устройства. Синхронизация iPhone и MacBook ещё не подключена.
- Для синхронизации требуется облачная база данных, авторизация и настройка секретных ключей проекта.
- Автоматическая загрузка курсов валют, налоговый учёт, возвраты и сверка с маркетплейсами пока не реализованы.
- До проверки на реальных устройствах и тестирования резервной копии не используй приложение как единственный источник финансового учёта.
