# BUBBLE BOOM — учёт бизнеса

Русскоязычное веб-приложение, которое можно добавить на главный экран iPhone через Safari.

## Что работает в версии 1.0
- Товары, артикулы, категории, единицы измерения и складские остатки
- Закупки в KRW, CNY и USD с фиксацией курса и стоимости партии
- Доставка привязывается к закупке отдельно; её можно изменить или удалить без двойного начисления
- Продажи с фиксацией себестоимости на момент продажи
- Учёт комиссии площадки, упаковки, доставки покупателю и других затрат на заказ
- Прочие расходы по категориям
- Калькулятор себестоимости материалов
- Редактирование и удаление записей с проверками складских остатков
- Полная резервная копия JSON и выгрузка разделов в CSV
- Корректная местная дата устройства; офлайн-кэш

## Публикация GitHub Pages
В репозитории открой **Settings → Pages**. В разделе **Build and deployment** выбери **Deploy from a branch / GitHub Actions** (если отображается выбор источника, выбери GitHub Actions). Сохрани настройку. После этого workflow сможет опубликовать приложение.

Если автоматическая настройка не проходит, это связано с тем, что подключённая GitHub-интеграция не имеет права самостоятельно включить Pages для репозитория. Настройка выполняется владельцем репозитория один раз.

## Установка на iPhone
После успешной публикации открой адрес GitHub Pages в Safari → «Поделиться» → «На экран Домой» → «Добавить».

## Что ещё не завершено
- **Облачная синхронизация iPhone и MacBook не подключена.** Сейчас данные находятся в хранилище браузера каждого устройства отдельно. Для синхронизации нужна отдельная облачная база, авторизация и секретные настройки проекта.
- Нет автоматического обновления валютных курсов.
- Возвраты, налоги и автоматическая сверка с Coupang не реализованы.
- До тестирования на реальных устройствах не используй приложение как единственный источник финансового учёта. Делай резервные копии.
