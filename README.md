# BUBBLE BOOM — учёт магазина

Первая веб-версия приложения для учёта материалов и расчёта себестоимости.

## Возможности
- база закупленных материалов;
- пересчёт цены закупки в KRW из CNY и USD;
- ручная настройка валютных курсов;
- калькулятор себестоимости изделия по расходу материалов;
- локальное сохранение данных в браузере.

## Запуск
Открой `index.html` в браузере. Данные хранятся локально в браузере устройства, поэтому для переноса на другое устройство потребуется отдельная синхронизация или экспорт.

## Следующие этапы
1. Складские остатки и партии закупок.
2. Продажи, выручка и прибыль.
3. История операций и экспорт резервной копии.
4. Общая база данных для телефона и компьютера.
